# Guía de Usuario - Copiloto de Reparaciones Celulares

Bienvenido a la guía rápida de uso del Copiloto de Reparaciones Celulares. Esta herramienta está diseñada para centralizar todas tus operaciones de diagnóstico y mantenimiento Android en un solo lugar.

## 1. Conexión de Dispositivos
- Conecta el dispositivo Android vía cable USB.
- Asegúrate de que la **Depuración USB** esté habilitada en las *Opciones de Desarrollador* del dispositivo.
- El dispositivo aparecerá automáticamente en la barra superior de la aplicación.
- Puedes usar la opción **Puente Inalámbrico (Wireless Bridge)** para conectar el equipo vía Wi-Fi y trabajar sin cables.

## 2. Herramientas de Mantenimiento (Debloater y Limpieza)
- **Debloater:** Accede a la pestaña de Aplicaciones. Aquí podrás identificar aplicaciones preinstaladas por el fabricante (bloatware) y deshabilitarlas de forma segura para ahorrar batería y RAM.
- **Limpieza (Cleaner):** Usa esta función para limpiar la memoria caché y archivos temporales residuales del sistema.

## 3. Respaldo de Datos (Backup)
- Ve a la sección de **Backup**.
- Selecciona si deseas respaldar aplicaciones, datos de aplicaciones o archivos multimedia.
- Define la ruta de guardado en tu PC y comienza el proceso. Es ideal hacerlo antes de cualquier flasheo o reseteo de fábrica.

## 4. Diagnóstico Inteligente y Asistente (Gemini AI)
- **Chat Asistente:** Si tienes dudas sobre un error específico, abre el Chat ADB y consúltalo con el asistente.
- **Análisis de Logs:** Si el teléfono se reinicia o las apps fallan, extrae un logcat y pásalo por el *LogAnalyzer*. La IA identificará la causa del error en segundos.

## 5. Extracción Forense y Seguridad
- En casos avanzados, puedes realizar un volcado forense para extraer información clave del sistema.
- La **Auditoría de Seguridad** te permite comprobar si el dispositivo ha sido comprometido o tiene permisos peligrosos activos.
